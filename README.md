This repository is for my chess engine. I want to create progressively better engines based mostly on the 
chessprogrammingwiki and the algorithms described there. Also implemented is the engine vs engine tournament, 
so I can calculate the Elo of each of my engines. It may be that some progression actually slows the engine down, 
resulting in a lower Elo score. 
# Currently implemented algorithms and or functions
### Negamax function
### Move ordering
### Time limits implemented
### Piece square tables
And currently working on the table hashing (Zobrist)
Will also calculate the Elo based on the engines playing against themselves and also for the puzzle solving Elo. Can also implement to lichess, but only for better engines, ie 2500+ elo
